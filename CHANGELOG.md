## История до введения changelog

- Работа через официальный экспорт Instagram: импорт папки
  `followers_and_following` целиком, без входа в аккаунт.
- Интерактивный одностраничный HTML-дашборд: кто не подписан на тебя,
  взаимные подписки и общий обзор.
- Отслеживание изменений: вкладки новых и потерянных подписчиков и
  подписок, сравнение любых двух периодов.
- Аватары и полные имена подтягиваются через Playwright без входа,
  кэшируются локально (метаданные и изображения раздельно, ошибки
  ретраятся всегда) и докачиваются в фоне с авто-регенерацией.
- Дашборд V2 по умолчанию с возможностью вернуть классический V1;
  чистка списков (активные заявки, недавно отписавшиеся).
- Упаковка релиза: `scripts/build-exe.ps1` собирает однофайловый
  `InstagramTracker-<версия>-win-x64.exe` через PyInstaller.
- Документация README со всеми возможностями и веб-страница `web/`.
- Подключение витрины: `store.yaml`, иконка 512×512, скриншоты.
