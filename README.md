# Instagram Tracker

Простой инструмент для анализа подписчиков и подписок Instagram через официальный экспорт данных. Генерирует красивый HTML-дашборд.

## Как пользоваться (пошагово)

### Шаг 1. Скачать архив Instagram

1. Открой в браузере:
   ```text
   https://accountscenter.instagram.com/info_and_permissions/dyi/
   ```
2. Войди в аккаунт и нажми **"Скачать данные"**.
3. Выбери:
   - **Some of your information** (не All).
   - **Connections → Followers and following**.
   - Формат: **JSON**.
   - Диапазон: **All time**.
4. Дождись письма со ссылкой и скачай архив.

### Шаг 2. Скопировать файлы в проект

Разархивируй архив. Найди папку:

```text
<архив>/connections/followers_and_following/
```

Скопируй **все** файлы из неё в папку проекта:

```text
data/import/
  blocked_profiles.json
  followers_1.json
  following.json
  hide_story_from.json
  recent_follow_requests.json
  recently_unfollowed_profiles.json
```

### Шаг 3. Сгенерировать дашборд

**Просто запусти батник:**

```text
generate.bat
```

Или через Python:

```bash
python main.py generate
```

### Шаг 4. Открыть дашборд

Открой файл `index.html` в браузере (двойной клик).

## Как делать снимки регулярно

Каждый раз, когда запускаешь `generate.bat`, программа:
1. Читает файлы из `data/import`.
2. Сохраняет снимок в `data/snapshots/` с текущей датой.
3. Генерирует `index.html` со всеми снимками.

**Важно:** если запускаешь `generate.bat` несколько раз в один день — снимок перезапишется (одна дата = один файл).

Чтобы увидеть изменения (кто подписался / отписался), нужно:
1. Сделать первый снимок (например, сегодня).
2. Через месяц — скачать новый архив, заменить файлы в `data/import`, снова запустить `generate.bat`.
3. На дашборде появятся вкладки «Изменения» и панель «Сравнить с».

## Установка (первый раз)

```bash
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
```

В `config/config.json` укажи свой `target_username`.

## Команды

| Команда | Описание |
|---------|----------|
| `generate.bat` | Создать HTML-дашборд из `data/import` (просто двойной клик). |
| `fetch.bat` | Загрузить аватарки и полные имена с Instagram (без логина). |
| `python main.py generate` | Создать дашборд через Python. |
| `python main.py fetch` | Загрузить аватарки через Python. |
| `python main.py history` | Показать сохраненные снимки. |
| `python main.py config` | Показать конфигурацию. |

## Аватарки и полные имена (опционально)

Instagram не включает аватарки и полные имена в экспорт. Но их можно получить
без авторизации, загрузив публичные страницы профилей:

```text
fetch.bat
```

Программа откроет каждый профиль в headless-браузере и извлечёт:
- аватарку
- полное имя
- количество подписчиков, подписок и постов

Результат сохраняется в `data/profiles.json` (кэш). При следующем `generate.bat`
аватарки появятся в дашборде.

**Важно:**
- Процесс занимает ~2-3 секунды на профиль (300 профилей = ~15 минут).
- Уже загруженные профили пропускаются (кэш). Используйте `--force` для обновления.
- Может сломаться, если Instagram изменит страницу. Не страшно — дашборд работает и без аватарок.

## Дашборд

Интерактивная HTML-страница (тёмная тема) с боковым меню:
- **Обзор** — карточки-статистика (кликабельные), сводка изменений.
- **Анализ** — не взаимные подписки, фанаты, взаимные.
- **Изменения** — новые подписчики, отписались от меня, новые подписки, вы отписались.
- **Списки** — подписчики, подписки, недавно отписанные, заявки, скрытые истории, заблокированные.

Панель **«Сравнить с»** позволяет выбрать период (неделя, месяц, 3 месяца, год) или конкретный снимок для сравнения.

В каждом списке есть поиск по имени/нику и кнопка перехода на профиль Instagram.
Навигация работает без интернета — всё встроено в один файл `index.html`.

## Структура

```text
instagram-tracker/
├── app/
│   ├── config/         # config.json loader
│   ├── dashboard.py    # HTML generator
│   ├── main.py         # CLI
│   ├── models.py       # User + Snapshot
│   ├── parser.py       # Instagram export JSON parser
│   └── storage.py      # snapshots storage
├── config/
│   └── config.json     # target_username
├── data/
│   ├── import/         # JSON files from Instagram export
│   └── snapshots/      # saved snapshots for history
├── generate.bat        # run this to generate dashboard
├── main.py             # entry point
├── index.html          # generated dashboard
└── requirements.txt
```

## Ограничение

Instagram не включает `user_id`, аватарки и полные имена в экспорт. Ключом является `username`. Если человек сменит ник, программа посчитает его новым пользователем.
