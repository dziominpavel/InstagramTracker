# Instagram Tracker

Инструмент для анализа подписчиков и подписок Instagram через официальный экспорт данных. Генерирует интерактивный HTML-дашборд с аватарками, полными именами и отслеживанием изменений.

## Возможности

- Парсинг официального экспорта Instagram (JSON)
- Интерактивный дашборд в виде HTML (тёмная тема): **V2 по умолчанию** + классический **V1**
- Анализ: кто не подписан на тебя, кто фанат, взаимные подписки
- Отслеживание изменений: новые подписчики, отписавшиеся, новые подписки
- Сравнение с любым предыдущим снимком (неделя, месяц, 3 месяца, год)
- Автоматическая загрузка аватарок и полных имён (без логина)
- Локальное хранение аватарок — дашборд работает офлайн
- Поиск по каждому списку
- Переключатель «Классический вид» / «Новый вид» в шапке

## Как пользоваться (пошагово)

### Шаг 1. Скачать архив Instagram

1. Открой в браузере:
   ```text
   https://accountscenter.instagram.com/info_and_permissions/dyi/
   ```
2. Войди в аккаунт и нажми **«Скачать данные»**.
3. Выбери:
   - **Some of your information** (не All).
   - **Connections → Followers and following**.
   - Формат: **JSON**.
   - Диапазон: **All time**.
4. Дождись письма со ссылкой и скачай архив.

### Шаг 2. Скопировать файлы в проект

Разархивируй архив. Найди папку:

```text
<архив>/connections/followers_and_following/
```

Скопируй **все** файлы из неё в папку проекта:

```text
data/import/
  blocked_profiles.json
  followers_1.json
  following.json
  hide_story_from.json
  recent_follow_requests.json
  recently_unfollowed_profiles.json
```

### Шаг 3. Сгенерировать дашборд

**Двойной клик на `generate.bat`** или:

```bash
python main.py generate
```

Программа:
1. Читает файлы из `data/import`.
2. Сохраняет снимок в `data/snapshots/` с текущей датой.
3. Генерирует два дашборда: `index.html` (**V2**, по умолчанию) и `index-v1.html` (**V1**, классический).
4. Загружает аватарки (если есть недостающие) и обновляет оба файла.

### Шаг 4. Открыть дашборд

Открой файл `index.html` в браузере (двойной клик) — это новый вид (V2).

В шапке справа кнопка **«← Классический вид»** откроет `index-v1.html`. Из V1 можно вернуться кнопкой **«Новый вид →»**.

### Шаг 5. Обновить аватарки (опционально)

Аватарки скачиваются при `generate`. Чтобы они появились в дашборде — дождитесь окончания загрузки или запустите `generate.bat` ещё раз. Уже скачанные пропустятся, оба дашборда обновятся.

## Снимки и история

Каждый запуск `generate.bat` сохраняет снимок в `data/snapshots/` с текущей датой. Один день — один файл. Если запустить несколько раз в один день, снимок перезапишется.

Чтобы увидеть изменения (кто подписался / отписался):

1. Сделай первый снимок (например, сегодня).
2. Через месяц — скачай новый архив, замени файлы в `data/import`, запусти `generate.bat`.
3. На дашборде появятся вкладки «Изменения» и панель «Сравнить с».

Снимки можно делать нерегулярно — раз в неделю, раз в месяц, как угодно. Панель «Сравнить с» позволяет выбрать любой период или конкретный снимок.

## Установка (первый раз)

```bash
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
python -m playwright install chromium
```

В `config/config.json` укажи свой `target_username`:

```json
{
  "target_username": "your_username"
}
```

## Команды

| Команда | Описание |
|---------|----------|
| `generate.bat` | Создать дашборд + фоновая загрузка аватарок. |
| `python main.py generate` | То же через Python. |
| `python main.py generate --no-fetch` | Только дашборд, без фоновой загрузки. |
| `python main.py generate --date 2026-07-10` | Указать дату снимка вручную. |
| `python main.py fetch` | Загрузить аватарки с выводом прогресса в консоль. |
| `python main.py fetch --limit 10` | Загрузить только 10 профилей (для теста). |
| `python main.py fetch --force` | Перезагрузить все аватарки, даже свежие. |
| `python main.py history` | Показать сохранённые снимки. |
| `python main.py config` | Показать конфигурацию. |

## Дашборд

Два HTML-файла из одного набора данных:

| Файл | Версия | Назначение |
|------|--------|------------|
| `index.html` | **V2** (по умолчанию) | Dark Refined, спокойный UI, обзор с фокусом на изменениях |
| `index-v1.html` | **V1** | Классический вид — откат одним кликом из шапки |

В шапке: **«← Классический вид»** (на V2) и **«Новый вид →»** (на V1).

### Вкладки (V2)

| Группа | Вкладка | Описание |
|--------|---------|---------|
| Главное | Обзор | Сначала изменения за период, ниже метрики «Сейчас» |
| Анализ | Не подписаны | Ты подписан, они — нет |
| Анализ | Фанаты | Подписаны на тебя, ты — нет |
| Анализ | Взаимные | Подписаны друг на друга |
| Изменения | Новые подписчики | Подписались за период |
| Изменения | Отписались | Отписались за период |
| Изменения | Новые подписки | Ты подписался за период |
| Изменения | Вы отписались | Ты отписался за период |
| Списки ▾ | … | Подписчики, подписки, заявки и др. (свёрнуты по умолчанию) |

Вкладки «Изменения» появляются только если есть предыдущий снимок. Группа «Списки» в V2 свёрнута, чтобы не перегружать меню.

### Панель «Сравнить с»

Позволяет выбрать период для сравнения:
- **Кнопки**: Неделя, Месяц, 3 мес, 6 мес, Год, Всё время.
- **Dropdown**: конкретный снимок по дате.

Программа находит ближайший снимок к началу периода и сравнивает с ним. Все вкладки «Изменения» и цифры на «Обзоре» пересчитываются мгновенно.

### В списках (V2)

- Крупные аватары (если загружены) или круги с буквой.
- Полные имена, @username, счётчики.
- Поиск по нику и имени, сортировка.
- Кнопка «Открыть» — ссылка на профиль Instagram.

Оба файла работают офлайн (после загрузки аватарок).

## Аватарки и полные имена

Instagram не включает аватарки и полные имена в экспорт. Программа загружает их автоматически — открывает каждый профиль в headless-браузере и извлекает из meta-тегов:

- `og:image` — аватарка
- `og:title` — полное имя
- `og:description` — количество подписчиков, подписок, постов

**Без авторизации.** Не нужен логин или пароль.

### Кэширование

| Данные | Частота обновления | Почему |
|--------|-------------------|--------|
| Метаданные (имя, подписчики, посты) | 30 дней | Меняются регулярно |
| Аватарка (картинка) | 90 дней | Меняются редко |
| Профили с ошибкой (login_wall, timeout) | Каждый запуск | Блокировка может быть временной |
| Новые профили (нет в кэше) | Сразу | Очевидно |

Аватарки хранятся в `data/avatars/` как `.jpg` файлы. Метаданные — в `data/profiles.json`. Дата скачивания записывается в поле `cached_at`.

Если аватарка свежая (< 90 дней), но метаданные устарели (> 30 дней) — программа обновит только имя и статистику, не перезакачивая картинку. Это экономит трафик и снижает риск блокировки.

Дашборд работает и без аватарок — показываются цветные круги с первой буквой ника.

## Ограничения

- Instagram не включает `user_id` в экспорт. Ключом является `username`. Если человек сменит ник, программа посчитает его новым пользователем.
- Instagram не выгружает список «кто отписался от меня». Это определяется только сравнением снимков.
- Загрузка аватарок может быть заблокирована Instagram (rate limiting). В этом случае профили с ошибкой будут повторяться при каждом запуске, пока блокировка не снимется.
- Точность отслеживания изменений зависит от частоты снимков. Чем чаще — тем точнее периоды.
