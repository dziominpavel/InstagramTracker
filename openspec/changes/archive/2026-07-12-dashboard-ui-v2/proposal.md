## Why

Текущий HTML-дашборд функционален, но визуально пестрый (много эмодзи, цветов и пунктов навигации), главный контент ограничен `max-width`, а сравнение периодов и списки неудобны. Нужен современный V2 с фокусом на изменениях и спокойным UI, при этом V1 должен остаться доступным одним кликом, пока пользователь не выберет окончательный вариант.

## What Changes

- Ввести **два варианта UI**: V2 (новый, по умолчанию) и V1 (текущий, «классический»).
- Генерация: `index.html` = V2, `index-v1.html` = V1.
- В шапке справа — кнопка переключения («← Классический вид» / «Новый вид →»).
- V2: стиль Dark Refined, сайдбар без эмодзи, обзор «сначала изменения», богатые строки списков, full-width layout.
- Зафиксировать текущую реализацию как V1 (вынести в отдельный модуль / тег) перед внедрением V2.
- Позже один из двух UI можно удалить — это вне текущего change.

## Capabilities

### New Capabilities
- `dashboard-ui`: требования к HTML-дашборду — версии V1/V2, переключатель, навигация, обзор, период, списки, визуальный язык V2.
